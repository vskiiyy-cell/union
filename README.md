# union
**UNION — Профсоюзная организация**  UNION — организация, объединяющая работников для защиты их трудовых, социальных и экономических прав. Наша цель — создание справедливых условий труда, обеспечение достойной оплаты, защита интересов каждого участника и укрепление солидарности между работниками.
